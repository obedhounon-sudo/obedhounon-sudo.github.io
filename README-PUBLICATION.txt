# Portfolio personnel — Obed HOUNON

Ce dossier contient un site statique simple pour GitHub Pages.

## Publication

1. Créer un dépôt public nommé exactement `obedhounon-sudo.github.io`.
2. Envoyer `index.html`, `robots.txt` et `sitemap.xml` à la racine du dépôt.
3. Dans le dépôt, ouvrir **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche `main` et le dossier `/ (root)`, puis cliquer **Save**.
6. Attendre la publication. Le site devrait être accessible à :
   https://obedhounon-sudo.github.io/

## Avant publication

- Vérifier que le nom du dépôt correspond exactement au nom GitHub.
- Tester les liens GitHub et itch.io.
- Vérifier que les descriptions du jeu et les technologies sont exactes.
- L'adresse e-mail présente dans le site sera publique et pourra recevoir du spam. Envisager une adresse de contact dédiée ou un formulaire avant publication.

## Google

Après la mise en ligne :
1. Ouvrir https://search.google.com/search-console/
2. Ajouter une propriété de type **Préfixe de l'URL** : `https://obedhounon-sudo.github.io/`
3. Choisir la méthode **Fichier HTML** ou **Balise HTML** et suivre les instructions affichées.
4. Si Google demande un fichier de vérification, le placer à la racine du dépôt, sans le renommer.
5. Dans Search Console → Sitemaps, envoyer `sitemap.xml`.
6. Dans Inspection de l'URL, tester `https://obedhounon-sudo.github.io/` puis demander l'indexation.

L'envoi du sitemap et la demande d'indexation ne garantissent pas une apparition immédiate dans Google.
